1. 推測的硬體架構

依據目前 FPGA 專案運作方式推測：

    Main Application
            │
            │ 更新影像資料
            ▼
       Frame Buffer
          (DDR)
            │
            │ 持續讀取
            ▼
      Video Generator
            │
            ▼
         MIPI DSI TX
            │
            ▼
            LCD

運作概念

  • Main App 負責更新 Frame Buffer 內容
  • MIPI TX 持續從 Frame Buffer 讀取資料
  • MIPI Video Stream 持續輸出
  • LCD 持續接收 Video Packet
  • 畫面更新時，不需要重新初始化 LCD
  • 只需修改 Frame Buffer 內容即可

因此：

Panel Register 設定
≠
Video Pixel Data

兩者是獨立的。

Panel Register

  • Color Mode
  • Gamma
  • TE
  • Power Setting
  • Driver IC 參數

通常只在開機或 Reset 後設定一次。

Video Stream

  • RGB Pixel Data
  • 持續輸出
  • 即使畫面不變也會持續送出

因此：

修改圖片
=
修改影像記憶體

不需要重送 Initial Code。

2. Power On 時序整理

面板電源：

VDDIO = 1.8V
AVDD  = +6.2V
AVEE  = -6.2V

Step 1 - Power On

VDDIO
AVDD
AVEE

Step 2 - 等待電源穩定

T2 = 200 ms

Step 3 - RESETB 維持 Low

T4 = 10 ms

可理解為：

Hardware Reset Pulse

Step 4 - RESETB 拉 High

釋放 Reset

Step 5 - 等待 Driver IC 初始化

T5 = 20 ms

Step 6 - 送出 Initial Code

包含：

Enable
6bit 設定
Gamma Table
TE

等所有初始化命令。

Step 7 - Sleep Out

Command = 0x11
Wait = 100 ms

Step 8 - Display ON

Command = 0x29
Wait = 50 ms

Step 9 - Video Streaming

Frame #1
Frame #2
Frame #3
...

直到系統關機。

3. 6bit Mode 設定方式

在 Initial Code 中加入：

FF 05

然後：

D2
12 0C
5D 5D
00 00
08 57
04 00 00

若以程式表示：

write_reg(0xFF, 0x05);

write_reg(
    0xD2,
    0x12, 0x0C,
    0x5D, 0x5D,
    0x00, 0x00,
    0x08, 0x57,
    0x04, 0x00, 0x00
);

此設定為：

RGB666
R = 6bit
G = 6bit
B = 6bit

即：

6 / 6 / 6 Color Mode
重要結論

此設定屬於：

Panel Initialization Parameter

而不是：

Image Data

因此：

換圖片
不需重送

但：

LCD Reset
FPGA 重啟
系統斷電

之後建議重新執行完整 Initial Code。

可將此設定視為：

Panel 開機必要設定

而非一次性的永久設定。

4. 實際開機流程範例

power_on();

delay_ms(200);       // T2

reset_low();
delay_ms(10);        // T4

reset_high();
delay_ms(20);        // T5

send_init_table();   // 包含 FF05 + D2 6bit設定

send_cmd(0x11);      // Sleep Out
delay_ms(100);

send_cmd(0x29);      // Display ON
delay_ms(50);

start_video_stream();

之後：

Main App
    ↓
更新 Frame Buffer
    ↓
MIPI 自動送出新畫面
不需要再次執行 Initial Code。
