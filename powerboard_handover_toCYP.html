一句話：這塊板把 12–24 V 轉成 FPGA 核心板要的九條電，再經 J1 送進去。

XCZU1CG 核心板沒有 on-board PMIC，所有工作電壓都必須外部產生後，經其 castellated 邊的 J1 電源入口（30 pad）餵入——這是本板存在的唯一理由。除了供電，本板另負責把 USB／UART／debug 拉到 2.54 mm header，以及面板電源的軟體與手動開關。

接手前必讀：目標設計是「單一電源輸入」

第 9 節的參考電路圖 v1.1 畫的是雙輸入版本，該版本已於 2026-07-05 被客戶推翻。請以第 3、4 節的單一輸入規格為實作依據，不要照 v1.1 的 Sheet 1 施工。詳見第 2 節。

1交接範圍與邊界

先把「做什麼」和「不做什麼」講清楚，避免與既有 IOB 混淆。

本板負責

電源　六條 logic rails ＋ 三條面板 bias rails，經 J1（30 pad）送核心板

保護　輸入級 fuse／反接／TVS／soft-start／共模扼流圈

時序　supervisor／sequencer 控制上下電順序與 PG gating

介面　USB（Device 直通）、UART1、debug header、風扇 PWM，皆拉到 2.54 mm header

開關　面板電源的軟體控制 ＋ 手動切斷（SW1）

本板不負責

不取代第一代 IOB（3D_PRINT_16K_IOB_2V0）。馬達、加熱器、燈具、風扇陣列、感測器、ADC 等功能仍留在印表機既有主板上。

不含　核心板本體、面板、線材 harness、外殼機構、認證（CE／UL／FCC）、量產測試治具。

不含 MIPI　面板 MIPI 訊號走核心板底邊 FPC（J6／J7），本板只送 bias（J1 pad 19–26）。

不含 USB 通訊協定　協定由 Racer 提供規格（見 §7.3），本板只是實體直通。

5電源時序

由 U18 TPS386596 supervisor／sequencer 統一控制。時序錯誤會導致 FPGA 無法開機或面板殘影。

FPGA 側

Zynq UltraScale+ 規定：0.85 V core rails 必須早於 VCCO ／ 1.8 V。

Supervisor 需執行 sequencing ＋ power-good gating，全部軌 PG 成立後才釋放 PS_POR。

面板側

開機序：VDDIO (1.8 V) → AVDD (+6.2 V) → AVEE (−6.2 V)
T2 = 200 ms，T8 = 120 ms

關斷／放電序（反向）：AVEE → AVDD → VDDIO
T9 = 150 ms，T14 = 100 ms

面板 ±6.2 V 只在所有 logic rails 穩定後才致能。

與 USB 協定的唯一交集：0xA7 硬體重置

USB 通訊協定的 0xA7 指令包含「LCD panel discharge」動作。因此三顆面板 load switch（U17A/B/C）與 sequencer 必須支援受控降壓（AVEE → AVDD → VDDIO），使重置乾淨。除此之外，通訊協定與本板無關。

另有 SW1 手動開關，可獨立切斷面板高壓 bias，供 UV mask LCD 安全維修使用。

7.2USB 實體介面（已與客戶簽核）

五項已簽核確認

① FPGA ＝ USB Device、Raspberry Pi ＝ Host　② 對外 USB 接頭位於本板，訊號由核心板引出　③ 核心板所有電源由本板提供；Pi 與 FPGA 之間的 USB 線僅傳資料不供電　④ 電源接頭與 USB 接頭為兩個獨立連接器　⑤ 兩板共地，透過 USB cable GND 建立

兩處重要更正 —— 舊文件有誤，請以此為準

① D+／D− 對應 pad：舊 ICD 回覆寫「J3-10 ＝ D+、J3-11 ＝ D−」是錯的。以核心板第 5 頁 pad define 為準，正確為 J3-4 (DP)／J3-5 (DN)。J3-10／11 是 TXRXA_P/N，屬 PS-GTR 高速差動對，與 USB 2.0 無關。

② 舊 demo 板絲印：IOB v2.0（2026-01-30）上的 J30／J32 是 Type-A（Host 母座），為早期 demo 配置，不適用 Device 模式。一律以 Mini-USB Type-B（J8）為準。

VBUS：Device 模式下 5 V VBUS 由 Host 供應，本板僅作 VBUS 偵測，不得對外 source 5 V。（§3.1 的 5 V / 30 mA 是供板內 USB-UART bridge 用，不是供 VBUS。）

7.3USB 通訊協定（非本板範圍）

協定層由 Racer 提供規格文件《USB Communication Protocol Specification》（USB 2.0 High-Speed、Bulk EP_OUT 0x01、FIFO 10 slots、checksum、異常矩陣、Black Box 暫存器 0x80040000）。本板只是實體直通，唯一交集是 §5 所述的 0xA7 受控放電。

8.2操作溫度

全系統 0 ~ +70 °C（商規）—— 已於 07-05 定案

核心板本身為 0 ~ +85 °C（Zynq E-grade），但全系統上限由光固化 mask LCD 決定：該面板於 UV 列印時須 ≤ 50 °C，且無工業級版本。因此即使把核心板換成工業級，全系統仍卡在 0 ~ 70 °C。

工業級（−40 ~ +85 °C）僅能做到核心板層級（Zynq 改 I-grade、工業 eMMC、工業振盪器）。本案不走此路徑，依商規設計即可。
